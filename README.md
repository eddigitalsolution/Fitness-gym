# KINETIC ATHLETICS - Fitness Gym & Sports Performance Lab

High-contrast sports editorial performance training web application built with React, Vite, Framer Motion, and Tailwind CSS.

## Features
- **Kinetic Scroll Telemetry**: Dynamic athlete metric simulation (Strength, Endurance, Speed).
- **Sports Editorial Design**: Premium high-contrast dark aesthetic, custom typography, micro-interactions.
- **Interactive Modals**: Evaluation booking workflow & complete legal compliance protocols (Privacy, Terms, Waiver).
- **Responsive Layout**: Full mobile & touch optimization across devices.

## Tech Stack
- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Framer Motion, Lucide Icons
- **Deployment**: Cloudflare Pages / Static Hosting

## Development
```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
