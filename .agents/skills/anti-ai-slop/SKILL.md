# Anti-AI Slop & Design Excellence Rules

## Design Principles
1. **No Generic Visual Slop**: Avoid standard default templates, generic pure-white or plain black backgrounds without depth, low-contrast text, or repetitive icon blocks.
2. **Rich Color Palette**: Use curated, modern color systems (e.g. obsidian deep slate `#0a0c10`, vibrant neon emerald `#00e699`, soft cyan highlight `#38bdf8`, glassmorphism borders `rgba(255, 255, 255, 0.08)`).
3. **Typography Mastery**: Use high-grade Google Fonts (e.g. `Syne` or `Outfit` for bold display headings, `Inter` or `Plus Jakarta Sans` for body copy). Set appropriate line heights (`1.5` - `1.6`) and letter-spacing (`-0.02em` for headings).
4. **Dynamic Interaction & Micro-Animations**:
   - Subtle hover elevations (`transform: translateY(-4px)`).
   - Smooth focus outlines and button active states.
   - Glow effects (`box-shadow: 0 10px 30px -10px rgba(0, 230, 153, 0.3)`).
   - Glassmorphism backdrop filters (`backdrop-filter: blur(12px)`).
5. **No Visual Placeholders**: Never use broken image URLs or empty gray placeholders. Use SVG graphics, dynamic status indicators, canvas animations, or generated visual assets.
